# HIST-003: Comando update

Como usuário do `lup-skills`, quero um comando `update <skill-name>` que propague a
versão atual da skill (do repositório central) para os agentes selecionados,
substituindo a versão antiga onde já existir e instalando do zero onde não existir,
para não precisar rodar `remove` seguido de `add` manualmente a cada evolução de skill.

Status: entregue (spec-first, verified). PRD: [PRD — comando update](/prd/prd-cli-update).
AC completas: [AC — CLI Update](/ac/ac-cli-update).
